# Nest Story

A home inventory. Rooms, items, prices, and photos stay on this phone.

Package: `com.NestStoryMNG.NestStory`

Remote config: [N322.json](https://api2.blwsmartware.net/N322.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product | Type |
| --- | --- |
| `ns_pack_1` … `ns_pack_10` | Consumable coins |
| `ns_remove_ads` | Non-consumable |
| `ns_pro` | Non-consumable, more than 8 items |

Eight items are free. Nest Story does not upload the inventory.
